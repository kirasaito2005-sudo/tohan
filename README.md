# 薬名ドリル

登録販売者向けの、OTC医薬品の **成分名・効能・代表的な製品・漢方処方** を覚えるための4択問題集です。
試験対策ではなく、店頭で「この成分は何の仲間で、何に効き、何に注意するか」を即答できることを目標にしています。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・サーバー不要）。

- **ドリル**: 出題範囲（薬効グループ）・問題形式・問題数を選んで開始
- **苦手を復習**: 直近で間違えた項目だけを出題
- **図鑑**: 成分／製品／漢方を検索・一覧。「暗記モード」で中身を隠してセルフチェック

学習記録はブラウザの localStorage に保存されます。

## 問題形式

| 対象 | 形式 |
| --- | --- |
| 成分 | 成分 → 分類 / 分類 → 成分 / 成分 → 作用 / 作用 → 成分 |
| 製品 | 製品 → 配合成分 / 成分 → 製品 / 製品 → 薬効 |
| 漢方 | 漢方 → 適応 / 適応 → 漢方 / 漢方 → 注意生薬（マオウ・カンゾウ・ダイオウ） |

## データ

- `data.js` に成分（約260）・製品（約65）・漢方処方（約60）を収録
- 成分の分類・作用・注意点は厚生労働省「登録販売者試験問題作成に関する手引き」の記載を要約
- 製品の配合成分は代表的なものを記載。`complete: false` の製品は主な成分のみのため、誤答の選択肢には同じグループの成分を使わないようにしています
- 製品の処方は改訂されることがあるため、店頭では最新の添付文書を確認してください

項目を増やすときは `data.js` の `INGREDIENTS` / `PRODUCTS` / `KAMPO` に追記してください。製品の `ings` には `INGREDIENTS` の成分名（または `aka` の別名）を書きます。
